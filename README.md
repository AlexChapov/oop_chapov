# Домашняя работа: Объектно-ориентированное программирование (ООП).


## Описание

1. **Продукты** — основной класс для товаров, который включает свойства, такие как название, описание, цена и количество. Также поддерживается возможность сложения стоимости двух продуктов.
2. **Категории** — класс для группировки продуктов. Поддерживает добавление продуктов в категорию и подсчет общего количества товаров.

## Структура проекта

- **CreateLoggerMixin** — миксин для логирования создания объектов.
- **BaseProduct** — абстрактный базовый класс для всех продуктов.
- **Product** — конкретная реализация продукта с поддержкой цены и количества.
- **Smartphone** — класс для смартфонов, наследуется от Product.
- **LawnGrass** — класс для газонной травы, наследуется от Product.
- **Category** — класс для категорий продуктов.

## Использование


### Создание продукта
product = Product(name="Смартфон", description="Смартфон с хорошей камерой", price=18000, quantity=10)

### Получение информации о продукте
print(product)

### Создание категории с продуктами
category = Category(name="Электроника", description="Товары электроники", products=[product])

### Добавление нового продукта в категорию
new_product = Product(name="Телевизор", description="Большой телевизор", price=25000, quantity=5)
category.add_product(new_product)

### Вывод продуктов в категории
print(category.products)
